Preguntas Frecuentes

¿Cómo acceder al servicio? expand_more
Es muy simple: 1. Completa el formulario de contacto. 2. Un asesor experto te contactará. 3. Recibirás las mejores ofertas comparadas. 4. Tú decides cuál es la mejor opción para ti.
¿Debo cambiarme de Isapre si recibo la asesoría? expand_more
No, no es obligatorio. Nuestra asesoría es para orientarte; si tu plan actual es el mejor disponible para tu perfil, te lo informaremos transparentemente.
¿Es necesario entregar toda la información? expand_more
Sí, para una personalización efectiva de tu plan, necesitamos datos precisos como renta, cargas y preferencias clínicas, asegurando que la recomendación sea 100% útil.
¿Aún existen los planes compensados? expand_more
Sí, ayudamos a optimizar tu 7% de cotización obligatoria para que obtengas la mejor cobertura posible sin pagar de más, aprovechando cada peso de tu cotización legal.
¿Qué sucede con enfermedades preexistentes? expand_more
Toda enfermedad preexistente debe ser declarada. Los criterios médicos de las Isapres determinan la aceptación, y nosotros te asesoramos sobre cómo realizar este proceso correctamente.
¿Qué es el GES/AUGE? expand_more
Es el sistema de Garantías Explícitas en Salud que asegura acceso, calidad, oportunidad y protección financiera para un listado específico de enfermedades frecuentes.
¿Qué es el CAEC? expand_more
Es la Cobertura Adicional para Enfermedades Catastróficas, un beneficio que permite financiar hasta el 100% de los gastos derivados de atenciones de alto costo una vez cumplido un deducible.
